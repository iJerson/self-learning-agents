# Lessons

Small, durable project knowledge that doesn't rise to the level of a skill —
one-off observations, conventions discovered the hard way, gotchas worth not
re-learning. If something here recurs 3+ times or turns out to be
error-prone/non-obvious/tool-specific, propose promoting it to a skill via
`skill-factory` instead of leaving it here indefinitely.

Format: one entry per lesson, dated, single paragraph. Newest at the top.
